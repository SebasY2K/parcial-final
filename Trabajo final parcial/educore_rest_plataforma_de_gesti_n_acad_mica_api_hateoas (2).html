El proyecto implementa los cuatro endpoints solicitados:
1. Consulta general de los estudiantes (GET /api/estudiantes).
2. Consulta individual de un estudiante por su número de identificación (GET /api/estudiantes/{identificacion}).
3. Ingreso de nuevos estudiantes a la base de datos (POST /api/estudiantes).
4. Exportación de reportes básicos en formato PDF (GET /api/estudiantes/reporte/pdf).

Asimismo, las respuestas del API aplican el principio HATEOAS (mediante EntityModel y CollectionModel), cuenta con documentación interactiva en OpenAPI / Swagger UI (/swagger-ui.html), todo el código fuente está documentado con Javadoc y se encuentra integrado con su respectivo Frontend web.
